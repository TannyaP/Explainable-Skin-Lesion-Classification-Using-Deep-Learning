# Explainable Skin Lesion Classification Using Deep Learning

## Overview

This project presents an explainable deep learning framework for automated skin lesion classification. The system uses transfer learning, ensemble learning, and visual explainability techniques to classify skin lesion images and provide interpretable predictions.

The project aims to support early analysis by combining accurate image classification with visual explanations and confidence-based predictions.

## Key Features

* Skin lesion image classification using deep learning
* Transfer learning using **ResNet-18** and **MobileNetV3**
* Model performance comparison
* Ensemble-based prediction
* Grad-CAM visual explanations
* Confidence and uncertainty estimation
* Image validation and preprocessing
* Interactive prediction interface using **Gradio**

## Datasets

The project uses skin lesion image datasets, including:

* **HAM10000**
* **Derm7pt**

The datasets contain dermoscopic images representing different skin lesion categories.

> The datasets are not included in this repository because of their size. Please download them separately and update the dataset paths in the notebook before running the project.

## Methodology

### 1. Data Preparation

The skin lesion images are prepared for deep learning through preprocessing and transformation steps. The workflow includes:

* Loading and organizing image data
* Image resizing
* Image normalization
* Data augmentation
* Dataset splitting for training and evaluation

### 2. Transfer Learning

Pre-trained deep learning models are fine-tuned for skin lesion classification:

* **ResNet-18**
* **MobileNetV3**

Transfer learning enables the models to use previously learned visual features and adapt them to the skin lesion classification task.

### 3. Model Evaluation

The models are evaluated using classification metrics such as:

* Accuracy
* Precision
* Recall
* Weighted F1-score
* Classification report
* Confusion matrix

### 4. Ensemble Learning

Predictions from multiple models are combined to improve the robustness and reliability of the final classification.

### 5. Explainable AI

**Grad-CAM (Gradient-weighted Class Activation Mapping)** is used to highlight the regions of an image that contribute most strongly to a model’s prediction.

This improves interpretability by helping users understand which image features influenced the classification result.

### 6. Interactive Interface

A **Gradio-based interface** allows users to upload a skin lesion image and receive:

* Predicted class
* Prediction confidence
* Uncertainty information
* Visual explanation using Grad-CAM


The project can also be run using **Google Colab** after uploading the notebook and connecting the required datasets.

## Results

The project compares the performance of ResNet-18 and MobileNetV3 and evaluates an ensemble-based approach using classification metrics and visual outputs.

The results include:

* Model performance comparison
* Classification reports
* Confusion matrices
* Grad-CAM visualizations
* Confidence and uncertainty outputs

## Limitations

* The model is dependent on the quality and diversity of the training data.
* Performance may vary for images captured under different lighting conditions or with different devices.
* The system is intended for educational and research purposes and is **not a substitute for professional medical diagnosis**.
